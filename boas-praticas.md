# Boas práticas de Git e GitHub

1. **Use branches para mudanças específicas:** mantenha a `main` estável e crie branches com nomes claros, como `feature/nova-funcionalidade` ou `fix/correcao-login`.
2. **Faça commits pequenos e descritivos:** agrupe mudanças relacionadas e escreva mensagens que expliquem o objetivo de cada commit.
3. **Sincronize sua branch com a `main`:** atualize-a com frequência para reduzir conflitos e identificar problemas cedo.
4. **Revise as alterações em Pull Requests:** explique o propósito da mudança, confira o diff e solicite revisão antes de mesclar.
5. **Mantenha segredos fora do repositório:** não versione senhas, tokens ou chaves; use variáveis de ambiente e arquivos ignorados pelo Git.
